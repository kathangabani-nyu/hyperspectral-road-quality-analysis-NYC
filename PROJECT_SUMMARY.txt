                            TECHNICAL DETAILS
================================================================================

Dataset:
  Name:           NYU TuckMapping Brooklyn 2019
  Format:         PCI .pix hyperspectral
  Size:           29.5 GB
  Dimensions:     6419 x 8001 pixels
  Bands:          288 spectral channels
  Data Type:      16-bit unsigned integer
  CRS:            EPSG:3178

Processing:
  Test Area:      500 x 500 pixels
  Location:       (2000, 3000) in pixel coordinates
  Total Pixels:   250,000 per test area

Features:
  Original:       288 spectral bands
  Augmented:      66 features (bands + indices + stats + spatial)
  Reduced:        50 PCA components (99% variance)

Training:
  Samples:        25,966 total (balanced)
  Train Set:      18,176 samples (70%)
  Test Set:       7,790 samples (30%)
  Validation:     5-fold stratified cross-validation

Classifier:
  Algorithm:      Random Forest
  Trees:          200
  Max Depth:      30
  Min Samples:    5 (split), 2 (leaf)
  Class Weight:   Balanced
