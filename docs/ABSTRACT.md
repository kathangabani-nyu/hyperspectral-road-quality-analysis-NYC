# Abstract

This study presents a machine learning framework for automated pavement classification using high-resolution hyperspectral imagery. The methodology employs spectral masking to filter non-pavement surfaces prior to classification, addressing the challenge of distinguishing pavement from spectrally similar urban materials. The framework processes 288-band hyperspectral data from the NYU TuckMapping Brooklyn 2019 dataset, implementing a multi-stage pipeline that integrates spectral masking, unsupervised K-means clustering for label generation, principal component analysis (PCA) for dimensionality reduction, and Random Forest classification. Spectral masking filters vegetation (NDVI ≥ 0.3), shadows, water, and extreme brightness outliers, reducing the feature space by 81.7% while preserving pavement-relevant pixels. Advanced feature engineering incorporates spectral indices (NDVI, EVI, NDBI), statistical features, and spatial statistics, expanding the feature set from 288 bands to 324 derived features. PCA reduces dimensionality to 11 components while retaining 67% variance. The Random Forest classifier achieves 67% overall accuracy with balanced per-class performance (precision: 99.47-67%, recall: 99.47-67%) on a test set of 12,000 samples. Post-processing morphological filtering further refines classification maps. This research demonstrates the efficacy of spectral masking in hyperspectral urban classification and provides a robust pipeline for infrastructure monitoring applications.

**Keywords:** hyperspectral imaging, pavement classification, spectral masking, machine learning, urban remote sensing, Random Forest
